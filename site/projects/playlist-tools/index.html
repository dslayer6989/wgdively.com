What the words mean

M3U / M3U8
A text file listing channels: one #EXTINF line with the name and details, then the stream link.
tvg-id
The channel's ID in the TV guide. If it's missing or misspelled, the channel shows no programme info.
group-title
The folder a channel appears in, like News or Sports.
XMLTV / EPG
The TV guide file: channel IDs plus what's on and when.

This tool doesn't test whether streams actually play. A browser can't do that reliably, and checking thousands of links would hammer the provider.

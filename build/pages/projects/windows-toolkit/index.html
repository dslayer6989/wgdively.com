Windows toolkit builder.

Setting up a new or freshly reset PC? Tick what you want, download one script, run it, and go make a coffee. Apps come from winget, Microsoft's own package manager that's built into Windows 10 and 11. Each app downloads from its official publisher.

How to run it

  1. Open your Downloads folder, right-click wgdively-setup.ps1 and choose Run with PowerShell.
  2. If a blue box asks about the execution policy, type Y and press Enter. If nothing happens instead, open PowerShell in your Downloads folder and run powershell -ExecutionPolicy Bypass -File .\wgdively-setup.ps1.
  3. Some installers ask for admin permission. Click Yes. When it says Done, restart the PC.

No winget? The script notices and opens App Installer in the Microsoft Store. Install or update it, then run the script again. Brand-new PCs sometimes need a few minutes of Windows Update first.

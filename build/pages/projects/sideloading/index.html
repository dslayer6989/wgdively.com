02 · Projects / Sideloading

TV sideloading helper.

"Sideloading" means installing an app that isn't in your TV's app store. It's allowed on all of these devices, but each one hides the switch somewhere different. Pick yours.

What are you installing on?

Amazon Fire TV

About 5 minutes. You only do steps 1–3 once.

  1. Install Downloader. On the home screen, go to Find → Search, type Downloader, and install the orange app by AFTVnews. It's free.
  2. Turn on Developer Options if you don't see it: Settings → My Fire TV → About, then click your device name (e.g. "Fire TV Stick 4K") 7 times until it says you're a developer.
  3. Allow Downloader to install apps: Settings → My Fire TV → Developer Options → Install unknown apps → Downloader → On.
  4. Get the app. Open Downloader, type wgdively.com/downloads in the address box and press Go. On the page, choose the Android TV · Fire TV file and press Download.
  5. When it finishes, choose Install, then Done. Downloader offers to delete the file. Say yes to save space.
  6. The app is in Settings → Applications → Manage installed applications, or hold the Home button and pick Apps to move it to your home row.

Android TV and Google TV

About 5 minutes. Menu names vary a little between brands.

  1. Install Downloader by AFTVnews from the Google Play Store on the TV.
  2. Turn on developer options: Settings → System → About, scroll to Android TV OS build (or Build) and click it 7 times.
  3. Allow Downloader to install apps: Settings → Apps → Security & restrictions → Unknown sources → Downloader → On. On some TVs it's under Settings → Device Preferences → Security.
  4. Get the app. Open Downloader, go to wgdively.com/downloads, choose the Android TV · Google TV · Fire TV file and press Download, then Install.
  5. Find it under Apps on the home screen. On Google TV, open Apps → See all apps, then hold Select on it to add it to your favourites.

Got a phone handy? Open the downloads page on your phone, tap QR next to a file and you'll see the same wgdively.com address the TV can open in Downloader.

Samsung smart TV (Tizen)

About 15 minutes the first time. You need a Windows, Mac or Linux computer on the same home network as the TV.

  1. Find your computer's address. On Windows, open Command Prompt and run ipconfig; use the IPv4 Address (it looks like 192.168.1.23). On a Mac, it's in System Settings → Network.
  2. Turn on Developer Mode on the TV: open Apps, then press 1 2 3 4 5 on the remote (on remotes without numbers, use the on-screen number pad). Switch Developer Mode on, type your computer's address as Host PC IP, press OK.
  3. Restart the TV: hold the power button on the remote until the Samsung logo appears.
  4. Download the Nuvio TV Installer for your computer from the downloads page and open it.
  5. Choose Samsung, enter the TV's address (on the TV: Settings → General → Network → Network Status → IP Settings), and press Install / Update. The installer downloads the right Nuvio TV build, signs it for your TV and installs it.
  6. Nuvio appears in Apps on the TV. Use the installer's Install / Update again for new versions.

Which TVs? 2021 and newer models (Tizen 6+) get the full build. 2018–2020 models (Tizen 4–5.5) get the legacy build. The installer picks for you. Use the same computer for updates: it keeps your TV's signing certificate, and Samsung only accepts updates signed with the same one.

LG smart TV (webOS)

About 15 minutes the first time. You need a computer on the same home network and a free LG Developer account.

  1. Make a free account at webostv.developer.lge.com.
  2. On the TV, install Developer Mode from the LG Content Store, open it and sign in with that account.
  3. Switch Dev Mode Status on (the TV restarts), open the app again and switch Key Server on. Note the passphrase it shows and the TV's IP address.
  4. Download the Nuvio TV Installer from the downloads page, open it, and choose LG TV.
  5. Enter the TV's IP address and the passphrase, then press Install / Update. Nuvio appears in your apps.

Keep Developer Mode alive. The Developer Mode app shows a session timer. Open it every so often and press Extend, or LG removes sideloaded apps when the timer runs out. You can reinstall them with the installer.

House rules

How it's run

Your data stays yours

The tools run in your browser. Nothing you type is sent to this server. The few that need the internet, like DNS and IP lookups, say so.

Accurate over clever

Every command, port and setting here has been checked. If something's wrong, the contact form gets it fixed.

Built in the open

The site's source is public on GitHub, and every change goes through a reviewed pull request.

Hack responsibly

Security tools are for systems you own or have permission to test. Learn on the practice labs in the toolbox.

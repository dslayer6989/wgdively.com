Security checks

  • Have I Been PwnedHas your email turned up in a data breach?
  • VirusTotalScans a file or link with about 70 antivirus engines. Uploads are shared with security researchers, so don't upload private files.
  • SSL Labs Server TestGrades a website's HTTPS setup.
  • Security HeadersChecks a website's protective headers.
  • ShodanSearch engine for internet-connected devices. Look up your own IP to see what you're exposing.
  • GRC ShieldsUP!Checks which ports your router has open to the internet.
  • urlscan.ioSafely see what a suspicious link does.
  • 2FA DirectoryWhich sites support two-factor login, and what kind.

For a reverse lookup (PTR), just type an IP address like 1.1.1.1. The tool turns it into the right in-addr.arpa name for you.

How it works: your browser asks the chosen resolver directly using DNS over HTTPS. The results are what the public internet sees, which may differ from your home router's answer if you use local DNS like Pi-hole or AdGuard Home. AD means the answer was DNSSEC-validated.
